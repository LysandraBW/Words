# Words
**IMAGES BELOW!**

Ok. Imagine. You're reading a book. You stumble across a word. The word? Viviparous. What is that? You open Safari. You search it up. Something about reproduction. You close Safari. Woah. Twitter. Is anything happening? Something must be happening. You go on Twitter. Bam! In the blink of an eye, you've lost focus and you have viviparously forgotten how that word was used.

Behold, the reason for this project. I'd like to remember the words I've read (I'd also like to be able to recall when conversing with others) and I'd like to not be distracted. Word? Word. Words is a web application that allows readers to (1) take note of the unfamiliar words found in a book; and (2) practice said unfamiliar words with automatically generated quizzes. Yippee!

The fundamentals of this project have largely been completed. Naturally, some fine-tuning needs to be done, but that's tomorrow's issue.

<br>
 
### Running the Project Locally
You'll need to have two terminals open to run the front-end and back-end servers. You'll also need to have the database set up, meaning the tables and all, but I cannot lie I lost the file (so I'll get back to the zero persons reading this when I've remade it).
```
cd client; npm run dev
cd server; npm run dev
# or
cd client; yarn dev
cd server; yarn dev
# or
cd client; pnpm dev
cd server; pnpm dev
# or
cd client; bun dev
cd server; bun dev
```

### Roadmap
I'm still working on this project because I really do like it! So, here are the following things that I'll be developing in my spare time.
* **Standardize the Backend**: I need to fix up the backend. I'll leave it at that!
* **Standardize the UI**: I need to fix up the UI. I didn't prepare any wireframes (or mockups) and it's now biting me in the butt.
* **Focus Feature**: I want a feature where the user can focus on their reading and occasional word searches. Think nice backgrounds and ambient music.
* **General Flashcards**: I'd like users to be able to create flashcards that aren't coupled to a book or chapter.
* **Landing Page**: Yeah.
* **Light Mode**: Yeah 2x.
* **Cloud Storage**: As there's no cloud storage, users cannot directly upload an image. They instead have to provide the URL of an already hosted image. This is inconvenient and prevents some images from being loaded, so that's not fun. Yeah 3x.
* **Animations**: The page is a bit bare in terms of finesse. I'd like to add some "oomph".
